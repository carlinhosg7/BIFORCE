# BIForce Site V5

Projeto refeito do zero em Next.js + React + TypeScript + Tailwind CSS.

## Destaque desta versão

A imagem oficial do Hero não recebe brilho, brightness, contrast, saturate ou scale no hover.
Ao passar o mouse sobre a arte, somente uma camada de pequenos nós luminosos posicionados sobre a rede começa a piscar individualmente.

## Rodar

1. Copie a pasta para `D:\BIFORCE` ou execute `COPIAR_PARA_D.bat`.
2. Abra `D:\BIFORCE`.
3. Execute `INSTALAR_E_RODAR.bat`.
4. Abra `http://localhost:3000`.
