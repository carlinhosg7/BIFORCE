BIFORCE V9 — CATÁLOGO COMERCIAL

OBJETIVO
Transformar a home em uma página comercial voltada a geração de oportunidades.

ALTERAÇÕES
- Hero/carrossel mantido e com mensagens mais comerciais.
- Soluções descritas por problema e benefício para o cliente.
- Nova abordagem de "problemas que resolvemos".
- Aplicações/cases reescritos sem inventar números ou clientes.
- Treinamentos posicionados como oferta corporativa.
- Processo comercial mais claro em "Como trabalhamos".
- CTA final voltado a proposta/diagnóstico.
- index.html incluído apenas como lançador da aplicação Next.js.

TESTE LOCAL
npm install
npm run dev
http://localhost:3000

INDEX.HTML
O index.html aponta para http://localhost:3000 e não contém o site.
Para usar como lançador em um provedor, altere apenas a URL dentro do index.html para a URL onde a aplicação Next.js estiver rodando.
